# Sarcasm

There are (at least) 2 ways to convey sarcasm on the internet: adding a `/s` to the end of your statement, or alternating the case of each character:

> crypto is the future of finance! /s

> cRyPtO Is tHe fUtUrE Of fInAnCe!

As an internet troll, Dong spends his spare time making sarcastic comments on Reddit. He prefers aLtErNaTe cAsInG to convey sarcasm.

Write a C program that reads in an entire file and writes the sarcastic output into another file. The program should take 2 command line arguments: the input filename and the output filename.

```bash
./sarcasm essay.txt output.txt
```

Create the output file if it doesn't exist, and overwrite it if it does. The program should do basic error handling.
